# Skill: React Native Screen

## Activación

Cuando se cree una pantalla.

---

## Responsabilidades

Las pantallas:

- muestran información
- capturan interacción

No deben contener reglas de negocio.

---

## Estructura

Screen
  ├── hooks
  ├── services
  ├── components

---

## Reglas

Mantener componentes pequenos.

Evitar archivos mayores a 300 líneas.

Extraer componentes reutilizables.

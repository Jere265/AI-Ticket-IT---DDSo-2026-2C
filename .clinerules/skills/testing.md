# Skill: Testing

## Activación

Cuando se implemente una nueva funcionalidad.

---

## Objetivo

Toda regla de negocio debe poseer pruebas.

---

## Casos mínimos

### Happy Path

Comportamiento esperado.

### Error Path

Validación de errores.

### Edge Cases

Casos límite.

---

## Prioridad

1. Servicios
2. Entidades
3. Controladores

---

## Cobertura

Generar pruebas para:

- compras
- cancelaciones
- cupos
- resenas
- mensajería

# CU\-09 Ordenar Resultados

## Objetivo

Permitir al comprador ordenar los eventos encontrados.

## Actor Principal

Comprador

## Precondiciones

- Existe una lista de resultados.

## Flujo Principal

1. El comprador selecciona un criterio de ordenamiento.
2. El sistema reordena los resultados.
3. El sistema muestra la lista actualizada.

## Criterios Disponibles

- Precio.
- Fecha del evento.
- Puntaje del organizador.

## Postcondiciones

- Los eventos se muestran según el criterio seleccionado.

## Reglas de Negocio Relacionadas

- BR\-17 Ordenamiento de Eventos
- BR\-18 Puntaje del Organizador

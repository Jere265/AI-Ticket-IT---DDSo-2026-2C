# CU\-05 Ver Compras de un Evento

## Objetivo

Permitir que un organizador consulte las compras realizadas para uno de sus eventos.

## Actor Principal

Organizador

## Precondiciones

- El organizador posee eventos registrados.

## Flujo Principal

1. El organizador selecciona un evento.
2. El sistema recupera las compras asociadas.
3. El sistema muestra: 
    - Comprador.
    - Estado.
    - Cantidad de entradas.
    - Disponibilidad restante.

## Postcondiciones

- El organizador obtiene información de ventas.

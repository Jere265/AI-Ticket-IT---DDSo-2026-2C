# CU\-04 Ver Mis Compras

## Objetivo

Permitir a un comprador consultar las entradas adquiridas.

## Actor Principal

Comprador

## Precondiciones

- El comprador posee al menos una compra.

## Flujo Principal

1. El comprador accede a "Mis Compras".
2. El sistema recupera las compras asociadas.
3. El sistema muestra: 
    - Evento.
    - Estado.
    - Cantidad de entradas.
    - Días restantes cuando corresponda.

## Postcondiciones

- El comprador visualiza el historial de compras.
